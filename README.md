# hemakanth.github.io

My personal portfolio site — dark, terminal-inspired theme built with plain HTML/CSS/JS (no build step, works directly on GitHub Pages).

## Structure
- `index.html` — all page content/sections
- `style.css` — design system + layout
- `script.js` — typing animation, mobile nav, scroll reveal

## Editing
Open `index.html` and swap in your real name, bio, projects, experience, and contact links (search for placeholder text like "Project One", "Company Name", etc).

## Deploy to GitHub Pages
1. Create a repo named exactly `hemakanth.github.io` on GitHub.
2. Push these files to the `main` branch (see commands below).
3. Go to repo Settings → Pages → confirm source is `main` / root.
4. Your site will be live at https://hemakanth.github.io within a few minutes.

```bash
git init
git add .
git commit -m "Initial portfolio site"
git branch -M main
git remote add origin https://github.com/hemakanth/hemakanth.github.io.git
git push -u origin main
```
